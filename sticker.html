Etiquetas para comunicar estado de stock, pré-venda, promoções, novidades ou descontos. São o sinal visual mais rápido na PCDIGA. Tamanho único.

Variantes — Stock

Estados de stock

As variantes de stock vivem dentro do sticker — não são um componente à parte. Comunicam ao utilizador, num único sinal, se o produto está disponível, em pré-venda ou esgotado.

Em stock

Produto com stock confirmado, pronto a enviar.

Em stock

Pré-venda

Produto ainda não disponível, com data de lançamento futura. Cor própria (magenta/rosa) para se distinguir das outras variantes.

Usage

Do's & Don'ts

✓ Faz

Usar a variante semântica certa: available para stock, discount só para % numéricas.

✗ Evita

"Disponível" em sticker amarelo (discount). O utilizador associa cada cor a uma semântica.

✓ Faz

Máximo 2 stickers por card. Mais que isso é ruído.

✗ Evita

5 stickers num único card. O utilizador não consegue priorizar a informação.

✓ Faz

Texto curto e directo: "Pré-venda", "-30%", "Novo". Uma palavra é suficiente.

✗ Evita

Frases inteiras dentro de stickers: "Disponível em loja Lisboa". Sticker é etiqueta, não label.

Acessibilidade

Acessibilidade

Cor não bastaCada sticker tem texto explícito. Daltónicos identificam pelo texto, não só pela cor.
ContrasteTodas as combinações background+texto passam WCAG AA (verificadas no Figma).
Screen readerTexto interno é lido normalmente. Não usar aria-hidden.
TamanhoTamanho único, mantém 11–12px. Garante leitura em mobile sem competir com o título.
