Pattern · Área de cliente

Área de cliente

Espaço autenticado onde o utilizador consulta e gere a sua actividade na PCDIGA — encomendas, dados pessoais, favoritos, pedidos de assistência, reviews, subscrições. Layout shell fixo (menu lateral + conteúdo) que se mantém em todas as subpáginas.

Organizado por blocos Cada subpágina tem a sua própria documentação. Esta página cobre o shell partilhado — menu lateral e header — que aparece em todas.

Usage

Do's & Don'ts

✓ Faz

Item de menu activo com destaque claro (border laranja + texto bold). Utilizador sabe sempre onde está.

✗ Evita

Estado activo só a bold ou só a mudar cor. Diferença insuficiente entre ecrãs.

✓ Faz

Ordem do menu por frequência de uso: Encomendas primeiro (mais consultado), Ajuda no fim.

✗ Evita

Ordem alfabética. Faz sentido para bases de dados, não para utilizadores.

✓ Faz

"Terminar sessão" separado dos restantes items (com divisor). É acção diferente das outras.

✗ Evita

Logout como link igual aos outros. Aumenta risco de clique acidental.

Acessibilidade

Acessibilidade

Menu — item activoaria-current="page" no item ativo. Border laranja + bold não chega para screen reader sozinho.
Menu — landmark<nav aria-label="Área de cliente"> para identificar como navegação secundária.
Terminar sessãoÉ acção destrutiva (perde contexto). Confirmar com prompt inline ou modal, não logout imediato.
Menu mobileToggle com aria-expanded + aria-controls. Focus vai ao 1º item quando abre.
Ajuda (link externo)Se abre em nova aba, incluir rel="noopener noreferrer" + indicação visual/aural do target externo.
