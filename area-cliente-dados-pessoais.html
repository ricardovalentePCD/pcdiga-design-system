Dados Pessoais

Página onde o utilizador gere os seus dados: informação pessoal, password e moradas (entrega e faturação). Três cards separados por área lógica + modal dedicado para editar/eliminar moradas.

Porquê

Decisões UX

Password num card separado

Alterar password é acção diferente de actualizar dados. Ter form separado com o seu próprio GUARDAR evita erros — utilizador não muda password sem querer ao actualizar o email.

Moradas com tabs Entrega / Faturação

O utilizador raramente muda ambas as moradas ao mesmo tempo. Tabs reduzem ruído visual e ajudam a focar numa de cada vez.

Radio button para morada default

Uma morada é sempre a default. Radio button é a metáfora certa (única selecção) — checkbox implicaria que pode haver várias default, o que não é o caso.

Editar morada em modal, não inline

O form tem 9 campos. Inline expandiria muito o card e faria perder contexto das outras moradas. Modal isola o contexto de edição.

ELIMINAR dentro do modal, não no menu ⋮

Acesso via modal reduz eliminações acidentais. Utilizador tem de abrir o form e confirmar dentro dele — mais deliberado.

Usage

Do's & Don'ts

✓ Faz

Um GUARDAR por card. Utilizador guarda dados independentemente.

✗ Evita

Um botão GUARDAR global para todos os cards. Se o form da password falha, dados de utilizador também não guardam.

✓ Faz

Validar match "Nova password = Confirmar" antes de submeter. Feedback inline sem esperar pelo servidor.

✗ Evita

Erro só depois do POST. Utilizador escreve tudo e recebe erro sem saber o que corrigir.

✓ Faz

ELIMINAR morada com confirmação secundária ("Tens a certeza?") ou toast com "Anular" durante 5s.

✗ Evita

Eliminar directamente sem confirmação. Utilizador perde morada guardada há anos.

Mobile

Dados Pessoais em mobile

Cards fazem stack vertical (Dados → Password → Moradas). Modal de editar morada ocupa full-screen para dar espaço aos 9 campos.

Acessibilidade

Acessibilidade

Form labelsCada input com <label for="...">. Floating label continua acessível para screen readers.
Password fieldsautocomplete="current-password" e autocomplete="new-password". Toggle "mostrar" opcional.
Tabs moradasrole="tablist" + aria-selected. Setas do teclado navegam entre tabs.
Radio moradasTodos os radios partilham name="default-address". Setas navegam.
Modalrole="dialog", focus trap, Esc fecha. Primeiro campo recebe foco.
ELIMINARConfirmação secundária obrigatória. Se possível, undo via toast durante 5s.
